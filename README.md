Este repositorio documenta mi progreso, evolución y las distintas etapas de mi formación programando en Python a lo largo de los años. Contiene desde mis primeras prácticas hasta los ejercicios más recientes de mi carrera, sirviendo como una bitácora personal de mis códigos.
